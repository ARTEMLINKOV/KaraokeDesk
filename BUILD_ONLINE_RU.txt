СБОРКА KARAOKEDESK В ОБЛАКЕ (без установки Xcode/CMake на своём Mac)

Этот проект содержит GitHub Actions workflow: .github/workflows/build-macos.yml.
Он автоматически запускает сборку на macOS и сохраняет KaraokeDesk-macOS.zip как артефакт.

КАК ПОЛУЧИТЬ ПРИЛОЖЕНИЕ
1. Открой https://github.com/ и войди в аккаунт (или создай его).
2. Нажми + вверху справа -> New repository.
3. Назови репозиторий KaraokeDesk, выбери Public или Private, нажми Create repository.
4. На странице пустого репозитория выбери ссылку "uploading an existing file".
5. Перетащи ВСЕ файлы и папки из распакованной папки KaraokeDesk_macOS, включая скрытую папку .github.
   Важно: если веб-интерфейс не позволяет загрузить скрытую папку/папки целиком, используй GitHub Desktop
   или командную строку с git; workflow обязан находиться по пути .github/workflows/build-macos.yml.
6. Нажми Commit changes. После отправки файлов сборка должна запуститься автоматически.
7. Открой вкладку Actions в репозитории и выбери последний запуск "Build KaraokeDesk for macOS".
8. Дождись зелёной галочки. Внизу страницы запуска в разделе Artifacts скачай KaraokeDesk-macOS.
9. Распакуй ZIP на Mac и перенеси KaraokeDesk.app в папку Applications (Программы).

ЕСЛИ СБОРКА УПАЛА
Открой неудачный запуск во вкладке Actions, нажми на красный шаг и скопируй сюда последние 30–50 строк лога.
Тогда можно исправить конкретную ошибку.

ОГРАНИЧЕНИЯ
- Успешная компиляция ещё не означает, что все функции полностью готовы.
- Текущий прототип не смешивает звук YouTube внутрь микшера; звук YouTube идёт через системный вывод macOS.
- Управление параметрами GUI плагинов и выбор аудиоустройства внутри приложения пока не реализованы.
- Приложение не подписано Developer ID и не нотариализовано. При первом запуске macOS может показать предупреждение.
