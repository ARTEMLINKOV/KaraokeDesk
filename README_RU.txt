KaraokeDesk — macOS source project (prototype)
==============================================

Что задумано
------------
- Встроенная панель YouTube: вставить ссылку и открыть готовое видео-караоке.
- Отдельная встроенная веб-страница Apple Music с собственным каналом и цепочкой эффектов.
- Режим подавления вокала Apple Music в реальном времени удаляет центральную часть стереосигнала; вместе с голосом могут исчезнуть центральные инструменты.
- Два входных канала для двух микрофонов Audient EVO 4.
- Независимые цепочки AU/VST3 для Mic 1, Mic 2, YouTube и Master; сканируются только выбранные пользователем папки.
- Отдельное назначение физического входа аудиокарты на каждый микрофон.
- Прямой мониторинг микрофонов через основной выход, с mute/solo и индикаторами уровня внутри фейдеров.
- Четыре выбираемых слота эффектов на каждом канале; нажатие на название плагина открывает окно его параметров, стрелка справа позволяет заменить эффект.
- Запись выбранных дорожек Mic 1, Mic 2, Master, YouTube/system и Apple Music.
- Настраиваемый цвет интерфейса и прокручиваемая панель настроек.
- Тёмный интерфейс в стиле live mixer.

Честные ограничения текущего прототипа
--------------------------------------
Интерфейс прототипа оформлен в тёмном macOS-стиле; пустая область браузера остаётся тёмной. Это исходный проект, а не готовый подписанный .app. Его нужно собрать на Mac с Xcode и JUCE.
Плагины загружаются как AU/VST3, но интерфейс управления их параметрами пока не реализован:
плагин применяется со своими параметрами по умолчанию. Перестановка эффектов между слотами пока не реализована.
Встроенное YouTube-видео может не запускаться из-за ограничений сайта/авторизации/встроенного воспроизведения.
Если это происходит, кнопка открывает URL в системном web view; можно открыть ссылку в Safari отдельно.
Звук YouTube не смешивается в цифровом микшере приложения: браузерный звук идёт через системный вывод macOS.
При выборе записи YouTube приложение отдельно захватывает системный звук через ScreenCaptureKit; macOS
может запросить разрешение на запись экрана/системного аудио. Физический loopback и разрешения зависят
от версии macOS и настроек пользователя.
Это не законченный live-ready продукт, а базовый каркас для дальнейшей разработки.

Сборка на Mac
-------------
1. Установите Xcode и Command Line Tools.
2. Скачайте JUCE с https://juce.com/download/ и распакуйте, например, в ~/JUCE.
3. Установите CMake (например, через Homebrew: brew install cmake).
4. В Terminal перейдите в папку KaraokeDesk_macOS и выполните:
   cmake -S . -B build -DJUCE_DIR="$HOME/JUCE"
   cmake --build build --config Release
5. Приложение/бандл будет в папке build (путь зависит от версии CMake/Xcode).

Настройка EVO 4
---------------
- Подключите EVO 4 и два микрофона.
- Выберите входное устройство над каналами микрофонов и основной выход в разделе «Настройки». Выбранные аудиоустройства сохраняются между запусками.
- В настройках доступны частота дискретизации и размер буфера; меньший буфер уменьшает задержку, но может увеличить нагрузку на аудиосистему.
- Для AU/VST3 сначала добавьте папку вручную. Сканирование не обходит системные каталоги и проверяет только выбранные папки; найденные описания сохраняются локально и проверяются заново только при изменении файла плагина.
- Каждый плагин сканируется в отдельном процессе: кнопка ⏭ останавливает проверку текущего плагина и сразу переходит к следующему.
- Найденные плагины сохраняются в локальный кэш; при повторном сканировании неизменённые плагины не запускаются повторно.
- В настройках можно выбрать произвольный акцентный цвет интерфейса; выбор сохраняется между запусками.
- Нажмите кнопку с точкой для мониторинга входа через основной выход; начинайте с низкой громкости
  и используйте наушники, чтобы не допустить обратной связи.
- Чтобы звук YouTube/Apple Music проходил через фейдеры и мастер, установите BlackHole 2ch отдельно.
  В Audio MIDI Setup создайте Aggregate Device из EVO4 и BlackHole 2ch (включите Drift Correction для
  BlackHole), затем выберите этот агрегат как вход KaraokeDesk, а EVO4 — как выход. В настройках звука
  macOS выберите BlackHole 2ch как системный вывод. KaraokeDesk обнаружит его стереовход и направит
  браузерный звук в выбранный веб-канал микшера. Без этого настроенного входа используется ScreenCaptureKit
  как резервный захват, который не может отключить прямой системный вывод страницы.
- Кнопка Apple Music открывает music.apple.com во встроенном Chromium (YouTube остаётся на системном WebKit)
  и не запускает приложение «Музыка». Профиль Chromium, включая авторизацию, сохраняется в
  `~/Library/Application Support/KaraokeDesk/AppleMusicChromium`.
  Для локальной сборки скачайте CEF 156 для Intel с
  `https://cef-builds.spotifycdn.com/cef_binary_156.0.8%2Bg426920c%2Bchromium-156.0.8078.48_macosx64_minimal.tar.bz2`
  и укажите `-DCEF_ROOT=/путь/к/распакованному/CEF-SDK` (для сборки нужна macOS 14.5+ и Xcode 16+);
  готовое приложение сохраняет поддержку macOS 13+. CI использует тот же архив и проверяет SHA-256.
  Live-канал захватывает процессы CEF через ScreenCaptureKit.
  Для этого разрешите KaraokeDesk в
  System Settings > Privacy & Security > Screen & System Audio Recording. Защищённое воспроизведение Apple Music
  или изменения macOS могут ограничить захват.
- Разрешите доступ к микрофону в System Settings > Privacy & Security > Microphone.
- Для записи нажмите кнопку ●, выберите дорожки и нажмите «Начать запись». Каждая выбранная дорожка
  сохраняется отдельно в `Documents/KaraokeDesk Recordings/<дата-время>`; микрофоны и Master — WAV,
  системные аудиодорожки YouTube и Apple Music — CAF.

Что нужно доделать перед живым выступлением
-------------------------------------------
- Настройка буфера/частоты дискретизации и проверка выбора аудиоустройств.
- Окна управления параметрами AU/VST3 и перестановка эффектов между слотами.
- При использовании виртуального устройства соблюдать совпадение частоты дискретизации агрегата и устройства.
- Тестирование latency, plugin crash handling, feedback protection, clipping meter.
- Проверить YouTube Terms and playback restrictions for your use case.

Безопасность
------------
Сначала тестируйте с выключенным монитором/минимальной громкостью. Не включайте микрофоны в колонки рядом
с микрофонами: это может вызвать акустическую обратную связь. Для караоке используйте наушники или PA,
направленные от микрофонов.


Автоматическая сборка без локального Xcode
-------------------------------------------
В проект добавлен workflow GitHub Actions. См. BUILD_ONLINE_RU.txt: он объясняет, как запустить сборку на облачном macOS runner и скачать ZIP с приложением.
